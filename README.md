# Don't Break the Pattern — Privacy Policy

Privacy policy for **Don't Break the Pattern** (Android, `com.ninjanext.dontbreakthepattern`), an offline brain-puzzle game by [NinjaNext](http://ninjanexttech.com/).

Live at **https://ninjanext.github.io/Don-t-Break-the-Pattern-Privacy/** (also `/privacy-policy.html`), served by GitHub Pages from `main` / root.

In short: no data collected, everything stays on the device, no ads, no analytics, no accounts, and no permissions beyond vibration.

The source of truth lives in the app repository (`docs/privacy-policy.html` and `docs/privacy-policy.md`). To update: edit it there, bump the effective date, copy the HTML here as both `index.html` and `privacy-policy.html`, and push.
